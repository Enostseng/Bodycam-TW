## 下載與安裝

請下載下方附件 **Bodycam-TW-1.1.1-community.zip**，完整解壓縮，保留 `BodycamTW.exe` 與旁邊的 `packages` 資料夾。GitHub 自動產生的 Source code 壓縮檔不包含工具成品。

1. 在 Steam 完成遊戲更新，並完全關閉 Bodycam，包含背景程序。
2. 開啟 `BodycamTW.exe`，確認遊戲路徑，按「一鍵安裝繁體中文」。
3. 可透過「管理漢化」驗證檔案或移除還原。請保留遊戲資料夾內的 `.bodycam-tw` 備份。
